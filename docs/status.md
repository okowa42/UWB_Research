- **問い1（単一台昇降の到達点 ≈1061mm からどこまで下がるか）→ 下がらない**。最良 H4 で 1006mm。

- **問い3（H1〜H4 の優劣）→ 有意差なし**。タグ測位の発散率（tag_v>10m）は H0:3%/H1:1%/H3:5% と
  振れるが Fisher 検定 p=0.62〜1.00。**運用推奨は「配り方を変えても変わらない」**。

### 所見6（新）: 効くのは「高さ分散の総量」だけで、配り方は無関係。実現可能域では構造的に届かない
- **試行内の直接検証**: H3/H4 は試行毎に高さを引き直すため条件内で分散量が振れる。H4 で実現した
  未知アンカー高さ std が 192〜2044mm と10倍振れても、鉛直誤差との相関は **ρ=+0.03（p=0.77）＝無相関**。
- **統合則**: 全アンカー高さの std を共通軸に取ると、**E2c（複数台分散）の点が追補③（単一台昇降）の
  曲線に完全に乗る**。同じ std なら1台を高くしても複数台に散らしても精度は同じ。

  | 高さ分散 std | 単一台昇降（追補③） | E2c 複数台分散 |
  |---|---|---|
  | ~660mm | 1050mm（既知1台 3.5m） | 1012mm（H3） |
  | ~990mm | 1128mm（4.5m） | 1077mm（H1） |
  | ~1150mm | 1061mm（5.0m） | 1006mm（H4） |
  | 2811mm | 564mm（10m） | 到達不能 |
  | 12733mm | 134mm（40m） | 到達不能 |

- **改善が始まるのは std ≳ 1800mm から**（そこから概ね 1/std で改善）。実現可能域（高さ ≤5m）では
  std ≤ 約1200mm にしかならず、**プラトーに構造的に閉じ込められる**。100m 四方に対し高さ差 2.5m は
  アスペクト比 2.5% で、幾何としてはほぼ平面のままであるため。
- **σ_deploy 非依存の再確認**: config 既定 300mm と依頼準拠 1,000mm の両方で実行し全指標がほぼ一致
  （H0 鉛直 shape: 1128 vs 1128mm）。追補①の所見4と整合。
- 図: `results/e2c_anchor_v.png`（パターン別箱ひげ）, `e2c_tag_v.png`（対数軸・発散試行が見える）,
  `e2c_unified_height.png`（統合則）。`selfcal_figs/` へ共有済み。
- 副次的発見: 近共面ではタグ測位が**数%の試行で発散**（tag_v 最大 2.4e8 mm）。校正の収束失敗ではない
  （converged/rigidity_ok は全試行 OK）。**平均でなく中央値で評価する運用が必須**。
